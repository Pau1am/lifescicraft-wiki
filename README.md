# LifeSci-Craft Wiki 图片素材

Notion 版 Wiki（LifeSci-Craft）所用的图标、封面与功能截图，用于替代原先托管在公共图床上的图片。

## 目录

| 目录 | 内容 | 数量 |
|---|---|---|
| `icons/` | MC 原版物品 / 方块贴图，16×16 用 NEAREST 放大到 128×128（`item__*` 为物品，`block__*` 为方块） | 42 |
| `covers/` | 各页面的封面横幅（官方版本宣传图，缩放到最大宽 2000px） | 10 |
| `features/` | 「特殊功能」页的模组功能截图（来自各模组官方发布页 / 文档） | 7 |

## 如何引用

仓库必须是 **Public**，图片才能被 Notion 匿名读取。

```
# 原始链接（简单直接）
https://raw.githubusercontent.com/<用户名>/<仓库名>/main/icons/item__compass_00.png

# jsDelivr CDN（推荐：全球缓存、更稳更快）
https://cdn.jsdelivr.net/gh/<用户名>/<仓库名>@main/icons/item__compass_00.png
```
